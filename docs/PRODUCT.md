# Rubusoo product

Rubusoo is an interactive quotation workspace for exporters, manufacturers, trading companies and small B2B sales teams. The implemented commercial core follows inquiry → confirmed draft → immutable revision → Buyer Room → question/change request → acceptance snapshot → PI → deposit/won.

The primary signed-in navigation is Home, Quotes, Customers, Catalog, Templates and Settings. Buyer access never requires an account. Trial, Solo, Pro and Business send limits are enforced by the revision publishing service.

Unknown pricing is never inferred: manual inquiry fallback explicitly marks product, price and freight as missing or required.
